BEWARE Free Camera v1.0  (for BEWARE v015b)
============================================

This is an unofficial fan-made mod. It is NOT affiliated with or endorsed
by Ondrej Svadlena or anyone involved in BEWARE.

The mod is provided as-is, with no warranty of any kind. Use it at your
own risk and back up your save files first.

See LICENSE (MIT) for the mod's own code and NOTICE.txt for the bundled
BepInEx loader (LGPL-2.1).


INSTALL
-------
1. Copy ALL files and folders from this archive into the BEWARE game folder
   (the one that contains BEWAREv015.exe).
   When Windows asks about merging the "BepInEx" folder, choose YES / Replace.

2. Start the game. Once you can drive, press F1.


CONTROLS
--------
F1                  Toggle free camera
WASD                Move forward/back/strafe
Q / E (or Space)    Down / Up
Mouse               Look around
Shift               15x faster
Shift + Tab         60x turbo
Ctrl                Slow precise movement
Numpad + / -        Field of view
PageUp / PageDown   Change base flight speed
L                   Toggle daylight mode
T                   Teleport your car to the camera position


UNINSTALL
---------
Delete from the game folder:
  winhttp.dll
  doorstop_config.ini
  .doorstop_version
  BepInEx/

If something is wrong, check BepInEx/LogOutput.log after starting the game.
